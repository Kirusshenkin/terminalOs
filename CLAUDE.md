# Терминал для macOS

Нативное приложение: SSH, панель Docker, метрики сервера, управление ключами,
вход по Touch ID и собственный MCP-сервер. Полный план — `docs/PLAN.md`,
эскизы интерфейса — `design/`. Направление дизайна: фосфор (тёмное стекло,
свечение, скан-линии).

Swift 6.3, macOS 26+, SwiftUI + AppKit. Пакеты в `Packages/`, приложение в `App/`.

## Язык

Код, имена, комментарии и сообщения коммитов — по-английски. Строки,
которые видит пользователь, — по-русски. Не смешивать: `struct HostProfile`
с полем `displayName`, а в интерфейсе «Хост не отвечает».

## Конкурентность

Строгая проверка Swift 6 включена и не отключается ни для одного таргета.

- Сеть, парсинг и работа с файлами живут в акторах: `SSHConnection`,
  `DockerService`, `MetricsCollector`, `Vault`.
- Модели интерфейса — `@MainActor @Observable`. Больше ничего на главном потоке.
- `@unchecked Sendable` — только с комментарием, почему это безопасно.
  Без объяснения не проходит ревью.
- `Task.sleep` не используется как способ дождаться готовности. Готовность
  проверяется фактом: соединением, ответом, событием. Таймер — только
  как верхняя граница ожидания.

## Границы пакетов

Зависимости направлены в одну сторону: приложение знает про пакеты, пакеты
про приложение — нет. Ни один пакет не импортирует SwiftUI или AppKit,
кроме `TerminalCore` (он обязан, там NSView).

`MCPBridge` не зависит от интерфейса вообще: он должен запускаться и
тестироваться без окна.

## Ошибки

Ошибка либо обрабатывается, либо поднимается выше. Проглоченная ошибка —
дефект, даже если код компилируется.

- Никаких `try?` без комментария, что именно и почему допустимо потерять.
- `!`, `try!` и `fatalError` — только на инвариантах, которые нарушаются
  лишь при ошибке программиста, и с сообщением, объясняющим инвариант.
- Каждая ошибка, доходящая до пользователя, объясняет **что произошло и
  что делать**. «Не удалось подключиться» — плохо. «Прокси на 127.0.0.1:10808
  не отвечает: запущен ли V2Box?» — хорошо.
- Отличать «прокси лежит» от «сервер не отвечает» и от «отказ в доступе».
  Без этого диагностика превращается в гадание.

## Секреты

- Секрет никогда не попадает в `print`, `Logger`, крэш-репорт, аудит MCP
  и сообщение об ошибке. Логгировать можно идентификатор хоста, но не то,
  чем к нему подключились.
- Пароли, passphrase и TOTP живут только в Keychain под биометрией.
  В памяти — минимально возможное время, без копий в промежуточных строках.
- Скроллбэк терминала по умолчанию не пишется на диск. См. §7 плана.
- Никаких `print` в принципе: только `Logger` с категорией.

## Производительность

Терминал — это приложение, открытое весь день, и всё меряется этим.

- Байты из сети не кормятся эмулятору по одному: копятся окном ~16 мс
  и уходят пачкой. Перерисовка не чаще частоты дисплея.
- В горячем пути отрисовки нет аллокаций, форматирования строк и
  вычисления цветов. Всё, что можно посчитать заранее, считается заранее.
- Любой буфер ограничен сверху: скроллбэк, логи контейнера, история метрик.
  Неограниченный буфер — это утечка с отложенным сроком.
- Опрос замирает, когда окно неактивно или перекрыто.
- Анимации только на `transform` и `opacity`. Никакой анимации `blur`,
  теней и фильтров.

## Тесты

Обязательны для чистых функций, где ошибка тихая и дорогая:

- парсеры `/proc`, JSON от docker, `authorized_keys`, `~/.ssh/config`;
- подсчёт отпечатков ключей и загрузки ядер по дельтам;
- шифрование и миграции профиля, включая обрыв записи на середине.

Интерфейс тестами не покрываем. Сеть в тестах не трогаем — только фикстуры.

## Перед коммитом

```
./scripts/check.sh
```

Формат — `swift format` из тулчейна, правила в `.swift-format`.
Линт — `swiftlint`, правила в `.swiftlint.yml`.

Для ревью изменений: `/code-review`, для чистки без охоты за багами:
`/simplify`, перед релизом: `/security-review`.

## Чего не делать

- Не добавлять зависимость, если задача решается сотней строк своего кода.
  Каждая внешняя библиотека — это чужой график релизов.
- Не абстрагировать заранее. Протокол появляется, когда есть вторая
  реализация, а не когда она вообразилась.
- Не делать «на будущее». План большой, соблазн подготовиться велик,
  но незаконченные заготовки дороже, чем переписать потом.
