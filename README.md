# Phosphor

Терминал для macOS: SSH, панель Docker, метрики сервера, управление ключами,
автонастройка свежих серверов, вход по Touch ID. Интерфейс на русском и
английском.

Архитектура и решения — [`docs/PLAN.md`](docs/PLAN.md), макеты экранов — `design/`.

## Установка

Скачай `Phosphor.app.zip` со страницы релиза, распакуй, перенеси в «Программы».

**При первом запуске macOS покажет предупреждение** — приложение подписано
ad-hoc, без сертификата Apple Developer. Это не поломка, а карантин на всём
скачанном из интернета:

1. Двойной клик по приложению → появится предупреждение → закрой его.
2. Системные настройки → Конфиденциальность и безопасность → пролистай вниз →
   «Всё равно открыть».
3. Подтверди. Больше это не повторится.

Одной командой, если так удобнее:

```
xattr -dr com.apple.quarantine /Applications/Phosphor.app
```

Обновления приходят через Sparkle и ставятся самим приложением, поэтому
карантин на них не вешается: предупреждение бывает ровно один раз.

## Сборка из исходников

```
swift build -c release      # собрать
swift test                  # 61 тест
./scripts/bundle.sh         # собрать Phosphor.app в dist/
./scripts/check.sh          # формат, линт, сборка, тесты
```

Нужен Xcode 16+ или тулчейн Swift 6, macOS 14+.

## Что уже работает

| Модуль | Состояние |
|---|---|
| `PhosphorCore` | Экранирование, валидация, кольцевые буферы, фильтр escape-последовательностей, маскирование секретов |
| `VaultKit` | Шифрованный профиль ChaChaPoly, версия схемы, атомарная запись |
| `HostsKit` | Хосты, группы, теги, поиск, импорт `~/.ssh/config`, сниппеты |
| `SSHKit` | Транспорт через `ssh` с ControlMaster, SOCKS, проверка готовности фактом |
| `DockerKit` | Разбор `ps` и `stats`, команды логов и действий |
| `MetricsKit` | Снимки `/proc`, дельты по ядрам, steal, скорость сети |
| `KeysKit` | `authorized_keys`, отпечатки SHA-256 локально, защита от самоблокировки |
| `ThemeKit` | Пять тем, палитра ANSI, импорт `.itermcolors` |
| `ProvisionKit` | Профиль хоста, вердикт свежий/обжитой, рецепт из шести шагов |
| `PhosphorUI` | Экран входа, хосты, терминал с питомцем, Docker, мониторинг, ключи, тема |

## Безопасность

Модель угроз — §15 плана. Коротко: вывод сервера считается недоверенным вводом
(OSC 52 не пишет в буфер без спроса, терминал не отвечает на запросы отчётов),
секреты живут в Keychain под биометрией, профиль зашифрован, скроллбэк по
умолчанию не попадает на диск, параметры команд экранируются.

**Никаких интеграций.** Единственный сетевой трафик — SSH к твоим серверам и
загрузка appcast для обновлений. Ни телеметрии, ни аналитики.
