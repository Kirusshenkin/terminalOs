# Phosphor: первый запуск

Инструкция для тех, кто открывает Phosphor впервые. Десять минут — и у тебя
список серверов, терминал с сессиями, которые переживают закрытие окна, Docker
и метрики в одном месте.

Phosphor — приложение для macOS 26 и новее. Учётной записи нет, сервера
Phosphor нет: всё хранится на твоём Маке в зашифрованном виде.

## 1. Установка

```sh
curl -fsSL https://github.com/Kirusshenkin/terminalOs/releases/latest/download/Phosphor.zip -o Phosphor.zip
unzip -q Phosphor.zip -d /Applications
xattr -dr com.apple.quarantine /Applications/Phosphor.app
```

Или скачай `Phosphor.zip` со страницы релиза и перетащи приложение в
«Программы».

**При первом запуске macOS предупредит.** У приложения нет сертификата Apple
Developer, поэтому всё скачанное из интернета попадает в карантин. Это не
поломка:

1. Дважды щёлкни по приложению и закрой предупреждение.
2. Системные настройки → Конфиденциальность и безопасность → внизу
   **«Всё равно открыть»**.
3. Подтверди. Больше macOS не спросит.

Команда `xattr` выше делает то же самое одним шагом.

## 2. Вход

Приложение открывается экраном блокировки. **Нажми на круг** с подписью
«приложи палец» и подтверди:

- **Touch ID**, если на Маке или клавиатуре есть сенсор;
- **Apple Watch**, если разблокировка часами включена;
- **пароль учётной записи macOS**, если нет ни того, ни другого.

Логина и пароля у самого Phosphor нет. Под кругом написано, какие способы
входа доступны на этой машине.

Когда профиль уже есть, подтверждение спрашивается дважды подряд: первое
открывает окно, второе — ключ, которым зашифрован профиль. Так пока устроено
(issue #5).

## 3. Добавь серверы

Первый экран — «Список пуст — и это ненадолго». Phosphor уже посмотрел, что
лежит на этой машине, и предлагает перенести:

| Строка | Откуда берёт |
|---|---|
| импорт ~/.ssh/config | блоки `Host` с `HostName`, `User`, `Port` |
| известные хосты | серверы, к которым ты уже подключался через `ssh` |
| импорт из Termius | история подключений Termius |

Нажми **«перенести»** напротив нужной строки. После импорта справа от кнопок
видно, сколько добавлено и сколько не распознано.

Позже то же самое — на странице хостов: кнопка **«импорт…»** открывает список
источников. Сервер можно добавить и руками: **«добавить хост»** или **⌘N**.

- **адрес** — IP или имя, например `example.com`;
- **пользователь** — по умолчанию `root`;
- **порт** — по умолчанию `22`;
- **имя** — необязательно, без него возьмётся адрес;
- **теги** — через запятую, по ним работает поиск;
- **как дотянуться** — «напрямую» или «через прокси». Для прокси укажи хост и
  порт SOCKS5, например `127.0.0.1` и `10808` для V2Box.

Нужно зайти один раз, не сохраняя сервер? Набери `user@host` или
`user@host:port` в строке поиска и нажми **«подключиться»**. После входа
Phosphor предложит его запомнить.

## 4. Перед первым подключением к новому серверу

Phosphor подключается через системный `ssh` и проверяет ключ сервера строго.
Пока приложение само не спрашивает, доверять ли новому серверу, поэтому
**к серверу, к которому ты ещё ни разу не подключался, сначала зайди один раз
из обычного Терминала**:

```sh
ssh user@host
```

Сверь отпечаток с тем, что показывает хостинг, и ответь `yes`. Дальше Phosphor
подключается сам.

Вход — **по ключу**. Phosphor берёт те же ключи, что и `ssh`: из `~/.ssh` и из
`ssh-agent`. Вход по паролю пока не поддерживается.

## 5. Подключение

Щёлкни по карточке сервера. Откроется раздел **«терминал»**, над ним — строка
состояния: «собираю профиль хоста…», потом система сервера и аптайм.

Быстрее — с клавиатуры: **⇧⌘O**, начни печатать имя, адрес или тег, ↑↓ и
Enter. Сервер не из списка — впиши `user@host` или `user@host:порт`.
Переключиться на другой сервер можно и из шапки: щёлкни по имени хоста справа.

Если подключиться не вышло, в этой строке написано, что случилось:

| Сообщение | Что делать |
|---|---|
| прокси 127.0.0.1:10808 не отвечает — запущен ли V2Box? | Запусти прокси или проверь порт в карточке хоста |
| … отказал в доступе — ключа нет в authorized_keys? | Добавь свой публичный ключ на сервер или проверь пользователя |
| ключ хоста … изменился — подключение остановлено | Сервер переустановили — или кто-то подменяет соединение. Выясни, прежде чем «забывать» ключ в разделе «известные хосты» |
| … не отвечает | Сервер выключен, адрес неверный или порт закрыт фаерволом |

## 6. Терминал и сессии

Слева от терминала — колонка:

- **«этот мак»** — «обычный шелл» и локальные сессии tmux. Кнопка «+»
  появляется, если на Маке стоит tmux (`brew install tmux`).
- **«сессии»** — сессии tmux на сервере. «+», имя, Enter — новая сессия.
  Закрыл окно или приложение — сессия продолжает работать на сервере, при
  следующем входе всё на месте. Нужен tmux на сервере
  (`apt install tmux`). Правый клик → «снять сессию на сервере» завершает её
  вместе со всем, что в ней запущено.
- **«спейсы»** — серверы, открытые сейчас. Переключение одним щелчком.

Над терминалом кнопка **«разделить»** — до четырёх панелей, у каждой своя
сессия. Значок рядом меняет ориентацию. Разделение есть у сессий на сервере;
у «этого мака» одна лента.

Если в какой-то сессии программа ждёт ответа (например, кодирующий агент задал
вопрос), рядом с разделом «терминал» в шапке загорается жёлтая точка — её
видно из любого раздела.

## 7. Остальные разделы

Разделы в шапке переключаются мышью или клавишами:

| Клавиши | Раздел | Что там |
|---|---|---|
| ⌘1 | хосты | список серверов, ключи, проброс портов, сниппеты, известные хосты, журнал |
| ⌘2 | терминал | сессии и панели |
| ⌘3 | файлы | слева этот Мак, справа сервер. «←» скачать, «→» залить, файлы можно перетаскивать из Finder |
| ⌘4 | docker | контейнеры, их состояние и действия. «убить» и «удалить» спрашивают подтверждение |
| ⌘5 | мониторинг | ядра, память, диски, сеть, тяжёлые процессы, графики |
| ⌘6 | автонастройка | базовая настройка свежего сервера Ubuntu |
| ⌘7 | доступ ии | доступ Claude и других ИИ-клиентов к серверам, журнал их действий |
| ⌘8 | настройки | тема, стекло, язык, поведение, профиль |

Остальные клавиши — в строке меню, рядом с действием (**Файл**, **Терминал**,
**Хост**). Самые нужные:

| Клавиши | Что делает |
|---|---|
| ⌘T | новая сессия там, где ты сейчас (на сервере или на этом Маке) |
| ⌘D / ⇧⌘D | разделить вбок / вниз |
| ⌥⌘→ / ⌥⌘← | курсор в соседнюю панель |
| ⌘W | закрыть панель (сессия на сервере остаётся) |
| ⌘K | очистить терминал |
| ⌘F, ⌘G, ⇧⌘G | поиск по выводу, дальше, назад |
| ⌘= / ⌘- / ⌘0 | крупнее / мельче / обычный размер текста |
| ⇧⌘R | переподключиться к серверу и поднять упавшие панели |
| ⇧⌘O | быстрое подключение |
| ⌘N, ⌘E, ⌘⌫ | новый хост, править открытый, удалить открытый (с вопросом) |
| ⌘, | настройки |
| ⌃⌘L | заблокировать |

⌃-сочетания, ⌥ и ⌘←/→ Phosphor не занимает — они уходят в терминал.

**Автонастройка меняет сервер:** ставит пакеты, Docker и nginx, включает
фаервол и закрывает вход по паролю. Запускай её только на свежем сервере, где
SSH слушает порт 22, и сначала нажми «показать команды».

## 8. Сделай резервную копию профиля

Ключ, которым зашифрован профиль, живёт только на этом Маке. Если его не
станет — сменился набор отпечатков Touch ID, переустановлена система, куплен
новый Мак — профиль без копии не открыть.

**⌘8 → профиль → «экспорт профиля…»**. Придумай парольную фразу и сохрани файл
в надёжное место. Фразу не восстановить: забудешь — файл не открыть.

Чтобы вернуть профиль или перенести его на другой Мак: там же
**«импорт профиля…»**, выбери файл и введи фразу. Текущий список серверов
будет заменён содержимым файла.

## 9. Подключи ИИ-клиента (по желанию)

Phosphor может дать Claude Code, Claude Desktop и другим MCP-клиентам работать
с твоими серверами — без передачи ключей.

1. **Claude Code:** открой **⌘7 → доступ**, блок «подключить Claude Code», нажми
   «копировать» и выполни команду в обычном терминале. Она выглядит так:

   ```sh
   claude mcp add --scope user phosphor -- /Applications/Phosphor.app/Contents/MacOS/phosphor-mcp
   ```

   `--scope user` важен: без него мост виден только в той папке, где ты
   выполнил команду. Строка статуса в том же блоке покажет, видит ли Claude
   Code мост везде, только в одной папке или не видит совсем.

   **Claude Desktop и другие клиенты** — добавь в их настройки:

   ```json
   {
     "mcpServers": {
       "phosphor": {
         "command": "/Applications/Phosphor.app/Contents/MacOS/phosphor-mcp"
       }
     }
   }
   ```

2. Phosphor должен быть открыт и разблокирован.
3. **⌘7 → доступ.** Каждый сервер по умолчанию **выключен**. Включи нужному
   режим: «только чтение», «с подтверждением» или «полный». Пишущие действия в
   режиме «с подтверждением» появляются у тебя диалогом, и без «разрешить»
   ничего не выполняется.
4. Всё, что сделал ИИ, записано в **⌘7 → журнал**. Стереть этот журнал у ИИ
   нечем.

## 10. Если что-то не так

- **Экран блокировки не принимает Touch ID.** Нажми на круг ещё раз и выбери
  вход паролем учётной записи. После нескольких неудачных попыток macOS
  временно блокирует биометрию — это тоже снимается паролем.
- **Жёлтая полоса «профиль не сохранён…» или «профиль не сохраняется…»** над
  разделами. Изменения пропадут при закрытии окна. Сделай экспорт профиля (раздел 8) и сообщи о
  проблеме, приложив текст полосы.
- **Жёлтая полоса «…изменения не записываются, чтобы не затереть профиль пустым».**
  Профиль на диске есть, но не открылся: сменился набор отпечатков Touch ID,
  потерян ключ или файл повреждён. Список в окне пустой, и Phosphor намеренно
  ничего не пишет, чтобы не стереть настоящие серверы. Восстанови профиль из
  экспорта (раздел 8).
- **Сервер из импорта не подключается,** хотя из Терминала `ssh` работает.
  Проверь в карточке пользователя и порт: импорт из известных хостов и истории
  Termius не знает пользователя и подставляет имя пользователя Мака.
- **Нашёл уязвимость** — не открывай публичный issue, см. `SECURITY.md`.
