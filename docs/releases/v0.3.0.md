### По-русски

Phosphor 0.3 — про то, чтобы держать в одном окне и серверы, и своих
ИИ-агентов, и все свои Маки.

#### Нейронки прямо в терминале — без API-ключей

- **Выбор агента в новой панели.** Раздели экран (⌘D) — новая панель спросит,
  что в ней запустить: шелл, Codex, Gemini CLI, Cursor, opencode и других.
  Tab и стрелки выбирают, Enter запускает, Esc оставляет обычный шелл.
  Агенты работают как свои программы под твоей подпиской: Phosphor не
  спрашивает и не хранит ни одного ключа API.
- **Нет агента — подскажет, как поставить.** Если его нет на машине, Enter
  вставит команду установки, а запустить её решаешь ты.
- **Своя копия проекта для каждого агента.** Агент, запущенный в
  git-репозитории, садится в отдельный `git worktree` на новой ветке — два
  агента больше не ломают друг другу сборку. Убрать копию можно из рейла;
  с незакоммиченной работой она не удаляется.
- **Ответ агенту, не заходя в его панель.** Когда агент ждёт тебя, ответь
  прямо из рейла или из уведомления: «да», «нет» или свой текст.
- **Сплит на этом Маке.** Делить экран теперь можно не только на сервере,
  но и локально — агенты чаще работают именно здесь.
- **Файлы и картинки — перетаскиванием.** Брось файл или скриншот в панель —
  вставится путь, экранированный как в Terminal.app. Так картинку можно
  отдать агенту одним движком мыши.
- **MCP-мост для любых агентов.** На странице «Доступ ИИ» — готовая строка
  подключения для каждого агента (Codex, Gemini CLI, Cursor и других) и
  статус: видит он мост или нет. Что ИИ можно делать на каждом сервере,
  по-прежнему решаешь ты.

#### Синхронизация между своими Маками — без облака

- Профиль (хосты, группы, сниппеты, пробросы) синхронизируется через папку
  на **твоём собственном сервере** по SSH. Никакого нашего облака нет.
- Всё зашифровано: каждая запись — отдельно, ключ профиля завёрнут для
  каждой машины, ключи машин — в Secure Enclave.
- Новый Мак подключается по короткому коду, который сверяешь глазами на
  обоих экранах. Потерянную машину можно отозвать — ключ профиля сменится.
- Можно указать несколько серверов-хранилищ: один лежит — синхронизация
  идёт через другие, а он догонит, когда вернётся.
- Защита от подмены: хранилище не может подсунуть старую версию, чужой
  профиль или вернуть отозванную машину. Машина с убежавшими вперёд часами
  не утаскивает за собой остальные.

#### Серверы

- **Подключение через бастион** — цепочкой, каждый со своим ключом и прокси.
- **Мак как сервер.** Phosphor отличает macOS от Linux: метрики, установка
  tmux и встроенный рецепт настройки для Мака (Homebrew).
- **tmux в один клик** из рейла: root, sudo без пароля или с паролем.
- **Рецепты настройки:** выбор, импорт своих, рецепт по умолчанию для группы.
- **Даты ключей:** видно, когда ключ появился на сервере — и для ключей,
  добавленных агентом через MCP.

#### Мелочи, которые заметно

- **Питомцы.** Пиксельный котёнок в углу спит, пока ты работаешь. Можно
  нарисовать своего питомца сеткой символов и импортировать.
- **Окна закрываются кликом мимо**, если в них нечего терять; с
  несохранённым вводом — остаются и напоминают про «сохранить» и «отмена».
- Порядок вывода команд и лога настройки больше не перемешивается.

### In English

Phosphor 0.3 is about keeping your servers, your AI agents and all your Macs
in one window.

#### AI agents right in the terminal — no API keys

- **Pick an agent for a new pane.** Split the screen (⌘D) and the new pane asks
  what to run: the shell, Codex, Gemini CLI, Cursor, opencode and more. Tab
  and the arrows choose, Enter runs, Esc keeps a plain shell. Agents run as
  their own programs under your subscription: Phosphor never asks for or
  stores an API key.
- **Not installed? It tells you how.** Enter types the install command; running
  it is up to you.
- **A project copy per agent.** An agent started in a git repository gets its
  own `git worktree` on a new branch, so two agents stop breaking each
  other's build. Remove the copy from the rail; it is never removed with
  uncommitted work in it.
- **Answer an agent without opening its pane.** When an agent waits for you,
  reply from the rail or the notification: yes, no, or your own text.
- **Split on this Mac.** Panes now work locally too, not only on servers —
  that is where agents mostly run.
- **Drag files and pictures in.** Drop a file or a screenshot onto a pane to
  type its path, escaped the way Terminal.app does it — the quickest way to
  hand an image to an agent.
- **The MCP bridge for any agent.** The AI Access page has a ready line for
  each agent (Codex, Gemini CLI, Cursor and others) and shows whether it sees
  the bridge. What the AI may do on each server is still your call.

#### Sync between your Macs — no cloud

- Your profile (hosts, groups, snippets, forwards) syncs through a folder on
  **your own server** over SSH. There is no cloud of ours.
- Everything is encrypted: each record on its own, the profile key wrapped for
  every machine, machine keys in the Secure Enclave.
- A new Mac joins with a short code you compare on both screens. A lost Mac
  can be revoked, which replaces the profile key.
- Several storage servers: one is down, sync goes through the others, and it
  catches up when it is back.
- Tamper-proof: storage cannot roll back the profile, hand you a forged one or
  bring a revoked machine back. A Mac whose clock ran ahead no longer drags
  the others along.

#### Servers

- **Connect through bastions** — chained, each with its own key and proxy.
- **A Mac as a server.** Phosphor tells macOS from Linux: metrics, tmux
  install and a built-in setup recipe for a Mac (Homebrew).
- **tmux in one click** from the rail: root, passwordless sudo or sudo with a
  password.
- **Setup recipes:** pick, import your own, a default per group.
- **Key dates:** see when a key landed on a server — including keys added by an
  agent over MCP.

#### Small things you will notice

- **Pets.** A pixel kitten in the corner sleeps while you work. Draw your own
  pet as a grid of characters and import it.
- **Windows close on a click outside** when there is nothing to lose; with
  unsaved input they stay and remind you of Save and Cancel.
- Command output and the setup log no longer come out of order.
